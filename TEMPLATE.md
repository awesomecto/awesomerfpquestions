# Question Template

This file serves as a template for RFP question submissions. Each question should be submitted as a separate file in the `questions/` directory.

## File Format

Each question file should be named using the pattern: `category-brief-description.md`

For example:
- `technical-cloud-architecture.md`
- `security-data-protection.md`
- `financial-pricing-model.md`

## Content Structure

Each question file should follow this structure:

```markdown
---
category: [Category Name]
---

# Question

[Your RFP question here]

## Good Response

[Example of what constitutes a good response]

## What to Look For

[Key points evaluators should look for in responses]
```
